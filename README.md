# Calculator App

A responsive calculator web application built using HTML, CSS, and JavaScript. It supports basic arithmetic operations with a clean user interface and basic error handling.

---

## Live Demo

https://annett-george.github.io/Calculator/

---

## Features

* Addition, subtraction, multiplication, and division
* Percentage calculation
* Clear (AC) and delete (DEL) functionality
* Basic error handling for invalid expressions
* Responsive and minimal UI design
